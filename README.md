# ☕ Smart Cafe Revenue Intelligence Platform

**AI-powered Business Intelligence platform that predicts coffee shop revenue with 94.5% accuracy using XGBoost — deployed end-to-end with a live dashboard, Gemini AI business consultant, and automated PDF reporting.**


**🔗 [Try it live →](https://smart-cafe-revenue-analytics-system.onrender.com)**

---


## 🎯 The Problem

Small coffee shop owners rarely have access to data-driven forecasting tools — most rely on gut feeling to predict daily revenue, plan staffing, or evaluate marketing spend. This platform closes that gap: it turns operational metrics (foot traffic, staffing, marketing spend) into an accurate revenue forecast **and** a plain-English action plan, generated by AI.

---

## 📊 Model Performance

Trained and evaluated an XGBoost regression model on historical business data:

| Metric | Score | What it means |
|---|---|---|
| **R² Score** | **0.9447** | Model explains ~94.5% of the variance in daily revenue |
| **MAE** | 191.39 | Average prediction error of ~$191 |
| **MSE** | 55,561.40 | — |
| **RMSE** | 235.71 | Typical prediction error of ~$236 on daily revenue |

This isn't a toy model — an R² above 0.94 on real-world business data is a strong result, and the error margins are tight enough to be genuinely usable for planning.

## 🛠️ Tech Stack

**Frontend:** React.js · Vite · Axios · Recharts · Framer Motion
**Backend:** Flask · Flask-CORS
**ML:** XGBoost · Pandas · NumPy · Joblib
**AI:** Google Gemini API
**Data:** Google Sheets API (live sync)
**Deployment:** Render

---

## 📊 Input Parameters → Output

**Inputs:** customer count, average order value, operating hours, employee count, marketing spend, foot traffic, target revenue

**Outputs:** predicted revenue, achievement %, revenue gap, risk level, 7-day forecast, feature importance ranking, AI-generated recommendations, downloadable PDF report

npm run dev
